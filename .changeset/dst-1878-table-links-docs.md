docs(DST-1878): restore the Links section on the Table page

The Table page explains again when to put a link in a table and which `<Link>` variant to use. The section was lost during the docs migration. Its demo now shows venue websites as supporting links that open in a new tab, and a second demo shows a link-heavy events table that uses the `secondary` variant. The section also points to `textValue` for cells that hold a link, and notes that links opening a new window mark themselves.
